# FOOP-36 rendering contract

This suite holds the hand-authored acceptance contract for Foolish-mode ubca2
sequencing. Its one case and expected output were written from FOOP-36 before
the renderer existed; the renderer is repaired to match this fixed target.

The suite uses einmo's default `①` + newline separator. The `verified/` tier is
intentionally empty until a human reviews and signs the completed contract.
